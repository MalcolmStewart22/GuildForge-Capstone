# GuildForge (Capstone Project)

GuildForge is a **Unity-based idle simulation game** where the player runs a fantasy adventurers’ guild.

## Overview

In GuildForge, the player:
- Recruits adventurers
- Sends them on missions
- Upgrades their equipment

The project was built as an **initial prototype** to satisfy capstone requirements and explore the core systems behind an idle guild-management game.

## Project Scope

- Built in Unity using C#
- Designed as a mobile idle simulation
- Focused on gameplay systems rather than visuals

## Status

Finished capstone project.  
This represents **version one of the idea**, with room for future expansion and polish.
